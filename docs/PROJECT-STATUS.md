# STEPUE Project Status

## Current repository scope

This repository is for the **STEPUE Proof of Concept (POC) only**.

The POC documents the hardware, firmware, wiring, dashboard, BOM, diagrams, tests, and technical work completed so far.

## Final product

The **final STEPUE product is still under development**. It is intentionally **not posted or represented as complete** in this repository.

Future final-product work may change:

- Sensor configuration
- PCB and circuit design
- Power architecture
- Mechanical/enclosure design
- Firmware architecture
- Detection algorithm/model
- Haptic cueing implementation
- Data collection and validation methodology
- Connectivity and data storage
- Overall BOM

Therefore, components and design decisions in this POC should not be interpreted as the final product specification.

## BOM status

The included BOM is the **final BOM for this POC iteration**. It is not the final-product BOM. Components may be changed, added, removed, or replaced during subsequent development.

## Documentation rule

Any future final-product repository/documentation should be clearly separated from this POC repository so that the development history remains accurate.
