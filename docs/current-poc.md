# STEPUE — Current POC Status

## Objective

Investigate whether ankle movement and pressure information can be acquired in real time and classified into controlled gait states, including a predefined disturbed/FOG-like condition.

## Implemented

- ESP32 firmware and processing.
- MPU6050 acceleration and gyroscope acquisition.
- ADS1115 external ADC acquisition.
- FSR input through ADS1115 A0.
- Heuristic state machine: `STANDING`, `WALKING`, `FOG-LIKE CONDITION`.
- Local Wi-Fi communication.
- ESP32-hosted browser dashboard.
- Live sensor/state visualization.

## Current tuning/testing

- Movement sensitivity and state thresholds.
- FSR pressure response/calibration.
- Battery-only operation.
- Wi-Fi reliability during battery operation.

## What the FOG state means in this POC

The `FOG-LIKE CONDITION` state represents a predefined disturbed movement pattern generated by threshold rules. It is not equivalent to a clinically confirmed freezing-of-gait event and should not be described as a validated pre-FOG predictor.

## Timing

The current firmware contains a 100 ms delay in the main loop. Therefore the delay alone permits at most about 10 loop iterations per second; actual rate is lower because sensor acquisition, calculations, Wi-Fi handling and other operations also consume time.

## Current output

```text
IMU + FSR
   ↓
ESP32 acquisition
   ↓
Movement / gyro features + pressure level
   ↓
Heuristic state machine
   ↓
STANDING / WALKING / FOG-LIKE CONDITION
   ↓
Local Wi-Fi dashboard
```

## Explicitly outside current POC claims

- Clinical prediction accuracy.
- Diagnosis or treatment.
- Generalized performance across patients.
- A trained ML model.
- Prevention of FOG.
- Final haptic/motor cueing.
